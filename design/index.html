窗口外观

桌面软件的“窗口感”与个性化设计约定

圆角自绘窗口

无边框窗口，圆角 14px，1px 冷色描边 + 大范围柔和投影，悬浮于深色科技感壁纸上。

品牌渐变顶线

窗口顶端 3px 蓝→青渐变线（同 logo），是产品的视觉签名，也是窗口边缘的个性化点缀。

自绘标题栏

标题栏集成 logo + 模块名，右侧自绘最小化 / 最大化 / 关闭按钮，关闭悬停红色（#E81123）。

菜单栏收纳低频命令

标题栏下方一排「文件 / 编辑 / 视图 / 帮助」，收纳打开图片、导出、主题切换、检查更新等低频操作（附快捷键），工作区只保留高频工作流。

桌面衬托

原型页背景为深蓝青渐变壁纸（含细网格），衬托浅色窗口主体，突出“清爽”的界面内芯。

扩展原则

当前聚焦寸照处理，后续功能按以下约定平滑接入

工作区菜单切换模块

四个功能模块收纳在「工作区」菜单中，不再常驻侧边栏；未上线模块以「规划中 / 即将上线」徽标占位，界面更清爽。

统一设计令牌

颜色、圆角、阴影、控件全部收敛在 assets/app.css，改一处全局生效。

功能页模板

新增功能页：复制任一原型页，替换标题栏模块名与内容区，即可保持窗口外壳与导航完全一致。

渐进式发布

规划中的模块先出设计稿评审，实现一个上线一个；导航徽标随版本移除，用户可感知产品演进。
