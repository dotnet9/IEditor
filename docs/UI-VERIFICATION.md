# IEditor 0.3.7 界面与行为复核

验证基线：Windows x64，1320 × 860，简体中文和英文；CodeWF.Avalonia 12.1.4.20、CodeWF.Toolkit 1.0.0.19。原型与应用均使用同一组 Studio 主题资源。

## 可复现检查

- `dotnet test IEditor.slnx -c Release`：核心图像处理和几何换算，当前 8 项。
- `pwsh scripts/sync_localization_keys.ps1 -Check`：宿主 JSON 与 T4 强类型键、原型资源同步。
- `node scripts/prototype/build.cjs --check`：单文件原型可重建，兼容 LF/CRLF 检出。
- `node scripts/prototype/tests/audit-prototype.cjs`：将 HTML 复制到空目录，断网遍历 96 个工作区、语言、配色、明暗组合；检查导出、质量、参考线、关于与更新状态，禁止脚本错误、外部资源请求和英文界面残留中文。
- `dotnet run --project scripts/ui-verification/UiVerification.csproj -c Release -- artifacts/ui-managed`：离屏使用实际视图、视图模型和 Magick 图像引擎，不接触用户图片和偏好。
- `node scripts/prototype/tests/compare-layout.cjs artifacts/ui-managed artifacts/prototype-audit`：对照应用与浏览器实际输出的布局坐标。

原生验证器的发布与运行命令见 [发布流程](RELEASE.md)。GitHub 工作流在五个原生 runner 分别编译并执行验证器，再制作安装包。

## 逐页复核

| 页面 | 对照内容与修正 | 验证边界 |
| --- | --- | --- |
| 证件照 | 相同外壳、54 像素工具列、860 × 600 舞台、332 像素参数列；修复图标缩放、步进器、彩虹色板、英文换行、工具栏对齐及空态提示位置 | 原型使用样例照片，应用启动为空态；原生字体与参考线笔触有差异 |
| 批量处理 | 320 像素参数列、四列规格卡、36 × 36 缩略图、统一表头/行列宽、可用的删除按钮和并发选中态 | 原型固定 5 个样例并展示多种状态，验证器以 3 张合成图片执行真实处理；不将行数不同解释成渲染缺陷 |
| 设置 | 840 像素居中卡片，三态八色、语言即时更新、底部可滚动；关闭分段 ListBox 的自动滚动，避免页面进入时被滚动 34 像素 | 浏览器与 Semi 原生编辑器的边框、选中色环、行高略有差异 |
| 关于 | 标准窗口、真实版本、构建时间、平台、作者、仓库及更新入口；同一窗口切换中英 | 原型日期和版本为固定设计样例，应用读取真实元数据 |

每次截图旁均输出 `*.geometry.csv`。共同顶栏、状态栏及证件照舞台的 **28 个坐标/尺寸值** 已在 managed 和 Windows NativeAOT 版本对照通过，容差为 2 DIP；本机基线这几处坐标完全相同。例如舞台为 `(91,193,860,600)`，设置首卡宽 840，源图卡宽 332。

该坐标检查只覆盖明确列出的公共区域，不等于整页像素相似率。工具列总高、参数卡内文字换行和原生窗口按钮尚有可见差异；当前没有全页面积、字体和交互动画的统一评分算法，因此不宣称整页「95% 像素还原」已通过。

## 真实行为

验证器检查同一窗口在中英文间反复切换、标题栏选择不丢失、八色明暗共 16 组渲染及偏好 JSON 落盘、系统模式保存，以及真实版本和构建时间。

图像流程实际调用 Magick：一寸 300 DPI 为 295 × 413 像素；30 × 40 毫米、150 DPI 导出为 177 × 236；检查 PNG sRGB 元数据、导入去重、坏图错误行、单行删除、并发峰值为 2、未变化任务跳过、参数变更后重新处理、ZIP 内包含 3 个真实文件。所有图片均为隔离目录中生成的合成图片。暂停预览交互后，完成中的任务不得重启防抖定时器；本轮修复该竞态，避免导出被并发预览挡住。

更新流程用受控服务检查最新、发现版本、下载完成、安装、校验失败、取消、释放时中止、安装器请求退出和无适配资产时打开发布页；不会执行真实安装器或修改系统。底层下载和安装能力委托 CodeWF.Toolkit。

## 原生与平台限制

Windows x64 正式 NativeAOT 发布成功；独立 NativeAOT 界面验证器编译并实际运行成功，退出码为 0，生成 26 张截图及对应布局坐标。README 中的两张工作区图片来自该验证器通过 Skia 渲染的真实应用视图。

Ursa/Semi 的裁剪与 AOT 分析告警保留可见，不通过屏蔽告警宣称兼容。锁屏期间不进行人工桌面验收；离屏实际渲染不能代替文件选择器、系统拖放、窗口拖动和安装器交互。Linux/macOS 的原生结果以对应 GitHub Actions 任务为准。
