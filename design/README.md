# IEditor 界面原型

桌面端界面原型与设计规范。入口：`index.html`（原型总览 + 设计规范），直接双击任意 HTML 即可在浏览器中打开评审。

## 文件清单

| 文件 | 说明 | 状态 |
| --- | --- | --- |
| `index.html` | 原型总览：页面导航、窗口外观约定、设计令牌、扩展原则 | 设计规范 |
| `证件照处理.html` | 核心工作流：载入 → 尺寸规格 → 背景颜色 → 实时预览 → 导出 | v0.3 已实现 |
| `批量处理.html` | 扩展方向：批量导入、处理队列、统一参数、ZIP 导出 | 规划中 |
| `设置.html` | 外观、图像处理默认值、导出、更新与关于 | 随 v0.3 交付 |
| `assets/app.css` | 设计系统：全部设计令牌 + 应用外壳 + 组件样式 | 共享 |
| `assets/app.js` | 通用交互：分段选择、色板、规格卡、滑杆着色 | 共享 |

页面引用仓库根目录的 `../logo.svg`，无需额外图片资源。

## 设计原则

1. **清爽**：浅色主题，大量留白，卡片化布局，弱边框 + 柔和投影。
2. **科技感**：蓝→青品牌渐变（同 logo）、玻璃拟态顶栏、点阵网格底纹、预览区扫描动效、等宽字体呈现数值。
3. **可扩展**：功能 = 侧栏模块 + 独立页面；未上线模块用「规划中 / 即将上线」徽标占位；设计令牌全部收敛在 `assets/app.css`。

## 窗口外观（桌面软件个性化）

原型以「深色壁纸 + 圆角自绘窗口」呈现真实桌面软件观感：

- 无边框窗口，圆角 **14px**，1px 冷色描边 + 双层柔和投影；
- 窗口顶部 **3px 蓝青渐变品牌线**（与 logo 同源）；
- 自绘标题栏：logo + `IEditor — 模块名`，右侧最小化 / 最大化 / 关闭按钮，关闭悬停红色 `#E81123`；
- 桌面壁纸：深蓝青渐变 + 细网格，衬托浅色窗口主体。

落地实现（Avalonia）建议：`ExtendClientAreaToDecorationsHint="True"` 自绘标题栏，`WindowChrome`/`CornerRadius` 实现圆角与投影，渐变线为窗口顶部一个 3px 的 `Border`。

## 核心设计令牌

| 令牌 | 值 |
| --- | --- |
| 品牌渐变 | `linear-gradient(135deg, #2E6BFF, #00B8D9)` |
| 主色 / 辅色 | `#2E6BFF` / `#00B8D9` |
| 背景 / 卡面 | `#F4F7FC` / `#FFFFFF` |
| 文字（主 / 次 / 弱） | `#0F172A` / `#5B6B84` / `#93A1B8` |
| 边框 | `#E6EBF4`（弱）`#D8E0EE`（强） |
| 语义色 | 成功 `#12B76A` · 警告 `#F59E0B` · 危险 `#EF4444` |
| 圆角 | 控件 8–10 · 卡片 16 · 窗口 14 |
| 字体 | 系统栈（Segoe UI / 微软雅黑）；数值用 Consolas / Cascadia 等宽 |

## 新增功能原型

1. 复制任意功能页 HTML，文件名用功能的中文名；
2. 修改标题栏 `.win-module` 与 `<title>`；
3. 替换内容区，复用既有卡片 / 按钮 / 表单类；
4. 在各页侧边导航与 `index.html` 中加入入口（未实现则加「规划中」徽标）。
